## 一、项目目标

制作一款手机优先的单机网页版《新倚天屠龙记·单机精简版》。

不是重新设计“类似新倚天”的游戏，也不是GM修改器。

核心目标：

**尽量复刻《新倚天屠龙记》原版核心养成与氪金成长体验，删除联网、PVP、重复日常和纯商业拖累系统，用本地模拟充值体验氪佬成长。**

核心循环：

**主线推进 → 获得侠客 → 培养侠客 → 战力上涨 → 千宝塔/古墓 → 获得资源 → 继续培养**

中后期增加：

**经脉 → 功法 → 内力 → 神兵 → 神品觉醒 → 悟道**

---

## 二、开发方式

- 纯静态网页优先。
- 手机浏览器为第一使用端，同时兼容电脑。
- GitHub 仓库直接开发。
- GitHub Pages 作为发布方式。
- 不依赖服务器。
- 不需要账号系统。
- 不需要真实支付。
- 存档放浏览器本地。
- 支持 JSON 导入/导出存档。
- 后续可做 PWA，但不能为了PWA拖慢核心游戏开发。
- 技术栈优先原生 HTML + CSS + JavaScript，避免不必要的重框架和依赖。

## 十七、经脉

原版完整结构：

**13条经脉 × 6境界 × 10穴 = 780穴**

境界：

**通络 → 小成 → 贯通 → 大成 → 归一 → 圆满**

每境界最后为命门：

- 属性提升更高
- 消耗突破丹
- +20天赋

核心闭环：

**经脉 → 天赋 → 功法槽**

前中期尽量对齐原版。

后期材料出现明显运营膨胀时，开发完成后再平衡，不现在擅自砍。

## 三十四、第一阶段验收标准

第一阶段不是“界面有很多按钮”。

必须真的能玩：

1. 新游戏进入首页。
2. 有初始侠客并能组成阵容。
3. 能打主线。
4. 胜利能拿经验/铜钱。
5. 玩家能升级。
6. 会因为等级/战力卡住。
7. 能用体力速战获取经验。
8. 能培养侠客提高战力。
9. 能挑战千宝塔。
10. 能模拟充值。
11. VIP会提高。
12. 能买体力。
13. 能摇钱。
14. V8能解锁40888元宝黄衫女礼包。
15. 刷新浏览器存档仍然存在。
16. 可导出/导入JSON存档。
17. 手机端操作不需要横屏、不出现大面积溢出。

满足这些，才算第一阶段完成。

## 三十五、实现原则

1. **先能玩，再漂亮。**
2. **先完整循环，再扩内容。**
3. **数据和逻辑分离。**
4. **所有系统尽量配置化。**
5. **不主动新增系统。**
6. **不继续无目的考据。**
7. **开发遇到明确缺项才查原客户端。**
8. **不因为原版商业手游有某功能就默认必须复刻。**
9. **用户明确砍掉的功能不得自行恢复。**
10. **用户已确定的数值、侠客、解锁规则不得擅自修改。**
